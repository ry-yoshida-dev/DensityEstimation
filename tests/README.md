# Tests

## Overview

Unit tests for the `density_estimation` package, one file per method or result type.

## Components

| Component | Description |
| --- | --- |
| [`helpers.py`](helpers.py) | Shared synthetic datasets. |
| [`test_density_scores.py`](test_density_scores.py) | Tests for `DensityScores`. |
| [`test_density_samples.py`](test_density_samples.py) | Tests for `DensitySamples`. |
| [`test_grid_axes.py`](test_grid_axes.py) | Tests for `GridAxes`. |
| [`test_density_grid.py`](test_density_grid.py) | Tests for `DensityGrid`. |
| [`test_kde_processor.py`](test_kde_processor.py) | Tests for KDE parameters and processor. |
| [`test_mixture_processor.py`](test_mixture_processor.py) | Tests for GMM and Bayesian GMM parameters and processor. |
| [`test_mixture_components.py`](test_mixture_components.py) | Tests for `MixtureComponents` and `InformationCriteria`. |
| [`test_knn_processor.py`](test_knn_processor.py) | Tests for k-NN parameters, metrics, and processor. |
