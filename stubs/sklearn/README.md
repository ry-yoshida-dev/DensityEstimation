# sklearn stubs

## Overview

Type stubs for the parts of scikit-learn this package calls, because scikit-learn ships no complete types.

## Components

| Component | Description |
|-----------|-------------|
| [neighbors/](./neighbors/README.md) | `KernelDensity` and `NearestNeighbors`. |
| [mixture/](./mixture/README.md) | `GaussianMixture` and `BayesianGaussianMixture`. |
| [exceptions/](./exceptions/README.md) | `NotFittedError`. |
